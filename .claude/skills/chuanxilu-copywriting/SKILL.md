# 国风读书系列文案规范

适用：`chuanxilu/文案/epNN.md`。文案先行，**逐节交用户确认**，确认后标 ✅，未确认的小节不得进入成片。
旁白由本人克隆声合成（CosyVoice 3），文案里的节奏标注会直接变成合成参数，所以标注要认真写。

## 1. 为耳朵写作（硬规则）

| 规则 | 要求 | 反例 → 正例 |
|------|------|-------------|
| 句长 | 每个停顿单位 ≤20 字；整句 ≤35 字 | “他在经历了长达七天的苦思之后终于病倒” → “他撑到第七天，也病倒了” |
| 人称 | 每 2–3 句出现一次“你”；讲古人时拉回观众 | “世人皆困于此” → “你是不是也这样？” |
| 口语 | 书面词换口语；文言只出现在原典节，且紧跟白话 | “由此可见” → “所以你看”；“其” → “他的” |
| 具体 | 用数字、物件、动作，不用抽象词 | “很多资料” → “三百篇干货” |
| 同音 | 避免听不清的同音词与生僻字；必须用时紧跟解释 | “格物” → “格物，也就是去穷究” |
| 悬念 | 每 15–20 秒一个小钩子：问题、反转、数字、“但是” | — |
| 删 | 能删的字一律删；不写“我们来看看”“接下来” | — |

## 2. 七节骨架（每讲 3–5 分钟，旁白 900–1300 字）

| 节 | 时长 | 任务 | 检查点 |
|----|------|------|--------|
| 1 钩子 | 15–25 s | 观众昨天经历过的场景 + 反常识问题 | 前 3 秒内出现冲突；第一句就有“你” |
| 2 开放回路 | 20–35 s | 引出王阳明的故事，许诺结尾兑现 | 明确说出“答案在最后”或等价承诺；结尾必须兑现 |
| 3 原典登场 | 30–50 s | 竖排原文 + 逐句白话 | 原文 ≤40 字/段；每句白话紧跟；标出处 |
| 4 深讲（drop） | 50–80 s | 概念拆解 + 故事细节；音乐 drop 落在概念名上 | 一个概念讲透，不并列三个；有一句可被转述的金句 |
| 5 现代对照 | 30–45 s | 可对照的研究或现象 | 只说“对照/呼应”，不说“科学证明了王阳明”；数字有出处 |
| 6 误读与边界 | 25–40 s | 常见误读、争议、王学流弊；“这句不是王阳明说的”栏目 | 至少一条反面或边界 |
| 7 今日功课 | 20–35 s | 今晚就能做的一个具体动作 + 下一讲预告 | 动作可在 5 分钟内完成；兑现第 2 节的回路 |

古今双线：每节的“画面意图”写一组古今镜像动作（王阳明 ↔ 上班族），镜像点落在关键词上。

## 3. 节奏标注（直接驱动合成）

每句旁白行尾加标注，`build` 时解析：

```
他和一位姓钱的朋友，对着亭前的竹子日夜苦想。 〔快〕
这个人，叫王阳明。 〔慢｜留白0.8〕
道理，不在竹子上，在你自己心里。 〔慢｜金句｜留白0.9〕
```

| 标注 | 合成参数 | 用在 |
|------|----------|------|
| 〔快〕 | 语速 ×1.25 | 叙事、铺陈、过渡 |
| 〔中〕或不标 | 语速 ×1.18（全系列基准） | 一般讲解 |
| 〔慢〕 | 语速 ×1.05 | 揭示、人名首次出现、原典白话 |
| 〔留白N〕 | 句后停顿 N 秒（默认 0.25） | 金句前后、反转前 |
| 〔金句〕 | 屏上大字 + 字幕高亮；可单独用语气前缀 | 每讲 1–2 句 |

节奏规律：快句不连续超过 4 句；每节至少一处〔慢〕；金句前一句收短。

## 4. 原典与核查（诚实优先）

1. 每条原文写清来源层级：**《传习录》正文**（卷上/中/下 + 录名）＞ **书信**（如《与杨仕德薛尚谦书》）＞ **《年谱》** ＞ **后人记述/传说**。非正文在屏上标注来源。
2. 条目号以陈荣捷《王阳明传习录详注集评》为参照；**未核实前屏上不标条目号**。
3. 网传细节一律对照原文删改（例：“搬椅子对着竹子看七天”→原文“早夜去穷格”）。
4. 几处记载有出入时，文案从《传习录》，在 `chuanxilu/事实核查.md` 记下出入。
5. 现代研究：作者、年份、期刊、结论方向、复现情况查清再写；查不到出处的数字不上屏。
6. “这句不是王阳明说的”栏目：只澄清能查到原始出处或能确认无出处的伪名言。
7. 每写一节，同步更新 `chuanxilu/事实核查.md`（讲.节 | 说法 | 出处 | 状态）。

参考书（核查与找细节）：陈荣捷《王阳明传习录详注集评》、陈来《有无之境》、束景南《阳明大传》、钱穆《阳明学述要》。
写法参照：《让创意更有黏性》（SUCCESs 六原则）、麦基《故事》、《救猫咪》节拍表、休格曼《文案训练手册》（滑梯效应）、津瑟《写作法宝》；
讲史语感参照《明朝那些事儿》王阳明章节——只学语感，不搬内容与说法。

## 5. 每节交付格式

```
## 第 N 节 · <名称>（约 X 秒）⏳待确认

**旁白**
<逐句，行尾带节奏标注>

**屏上字幕要点**：<毛笔落版字、数字、印章>
**画面意图（古今双线）**：<一组镜像 + 卡点的关键词>
```

时长估算：按 5.5 字/秒（×1.18 基准）计，加所有留白。

## 6. 交付前自检清单（逐项过，查出的问题先改，再交用户）

- [ ] 第一句有冲突或“你”；3 秒内能抓人
- [ ] 每个停顿单位 ≤20 字；无连续 2 个书面腔句子
- [ ] 每 15–20 秒有一个钩子
- [ ] 本节至少一处〔慢〕；快句不连续超过 4 句
- [ ] 原文有来源层级；非正文已标注；未核条目号未上屏
- [ ] 无网传细节、无未核数字、无“科学证明了”
- [ ] 同音易混词已解释（格物、良知、致知……）
- [ ] 第 2 节的承诺在第 7 节兑现（写到第 7 节时回查）
- [ ] 事实核查表已同步
- [ ] 估算时长在本节区间内

交给用户时，只列出自检中**发现并已修改**的问题，不复述通过项。
