# 纸片风知识短视频（阿德勒引擎）

1080×1920、30fps、92.6 秒/期，配乐固定为 `music/bgm.m4a`（CLAUDE.md 强制），镜头边界、动作与音效全部落在 `bgm.detect()` 的实测拍点上。
现成范例：`adler/`（10 讲）、`nutrition/`（8 讲）、`scarcity/`（4 讲，首个全面使用光效层的系列，新系列优先照它写）。

## 1. 工作流

1. **事实核查先于分镜**：用 WebSearch 核实书中每个案例与研究（作者、年份、期刊、样本量、结论方向），同时查反面证据与复现情况。
   查不到原始出处的数字（网传“智商降 13 分”之类）不上屏；概念比喻、占比条一律在 `notes` 里写明“示意”。
2. **新建包** `<pkg>/`：`__init__.py`、`build.py`（复制 `scarcity/build.py`，改 `SERIES`、`PKG`、`OUT`、`MODS`）、`art.py`（系列专用元件）、`epNN_<key>.py`。
3. **写分镜**（见第 2、3 节），每期镜头小节数之和必须等于 42（引擎会校验）。
4. **检查**：`python3 -m <pkg>.build NN --sheet`（逐镜联系表 + 阅读窗警告），`--still 秒数` 看单帧细节。逐张看图，修正遮挡、溢出、字幕压画面。
5. **渲染**：`python3 -m <pkg>.build`（后台运行，单期约 3–5 分钟）。
6. **核验与交付**：`--verify`（时长、编码、响度 -14 LUFS、真峰值、音画偏差 ≤1 帧）→ `--publish`（复制到 `videos/<pkg>/`）→ 更新 README → 提交推送 → 打包 zip 发给用户。

## 2. 留存结构（每期 42 小节，固定骨架）

| 小节 | 时刻 | 段落 | 做法 |
|------|------|------|------|
| 0–2 | 0–4 s | **钩子** | 反常识问题用 `Pops` 逐词砸出，第 0 拍 `flashes=[0]`、`punch=0.025`，字幕留空（`text=""`）。第一秒内必须有画面事件。 |
| 2–4 | 4–8 s | **开放回路** | “看到最后……”“结果出人意料”，许诺一个后面才兑现的结论；配一个弹出的问号/钥匙 + `Spark`。 |
| 4–8 | 8–17 s | 情境铺垫 | 生活化情境，元素每 1–2 拍落一个（drop/pop + 音效）。 |
| **8** | **17.14 s** | **音乐 drop：概念落版** | `Big(..., rays=True, glow=True, shine=True, spark=True, sfx="kick")`，镜头 `punch=0.035, flashes=[0], shake=[0]`。 |
| 8–20 | 17–45 s | 机制讲解 | 示意动画 + 一个纯 `Pops` 的“金句”镜头（字幕留空）。 |
| **20** | **≈45 s** | **二次钩子** | “但更可怕的是……”“研究者真的做了……”，`flashes` / `Counter` 把注意力拉回来。 |
| 20–34 | 45–75 s | 研究证据 | `research=True`（≥4.5 秒阅读）；数字一律 `Counter` 滚动落定（带“叮”与星光）。 |
| 34–38 | 75–83 s | **质疑与边界** | 必须有：反面证据、复现失败、争议。角标用“常见质疑”。 |
| 38–40 | 83–87 s | 回报 / 下一讲预告 | 兑现开放回路或给一个可执行的小练习；`Rays` + 欢呼人物 + `Spark(sfx="clap")`。 |
| 40–42 | 87–92.6 s | 片尾 | `end_shot(REFS, 下一讲标题)`，参考资料 ≤3 条短引用。 |

节奏规则：
- 每 4–6 秒至少一个新的视觉事件（元素入场、数字落定、闪白、光效）；单镜头最长 4 小节（约 8.6 秒）。
- 段落边界小节 8 / 20 / 24 / 34 / 38 / 40 必须切镜。
- “多巴胺”反馈靠**小而密的奖励**：逐词弹出（每词一声 pop）、高亮词“叮”+星光、数字滚动落定。不要每镜都闪白——闪白与抖动只给钩子、drop、二次钩子和关键数字。

## 3. 光效与动效 API（`adler.core`）

| 元素 / 参数 | 作用 | 要点 |
|-------------|------|------|
| `Pops(words, x, y, size, at, step=1, layout="row"/"col")` | 文字逐个弹出（过冲回弹 + 星光） | 空格分词、`|` 换行、`【词】` 高亮为强调色纸片（音效 `ding` + 放射线）；整数拍上的词自动配 `pop` 音效；`step=0.5` 时半拍上的词无音效。 |
| `Big(..., rays, glow, shine, spark)` | 概念大字 | 四个开关默认关闭；drop 处全开。 |
| `Glow(x, y, r, alpha, pulse)` | 随节拍呼吸的背光 | 放在主体元素之前（先画在下层）。 |
| `Rays(x, y, r, alpha, n, spin)` | 旋转光束 | 强拍自动增亮；alpha 0.15–0.25 足够，别盖过内容。 |
| `Spark(x, y, at, sfx=None)` | 星光粒子爆散 | 0.9 秒内消失；跟在“弹出”的图标后面最有效。 |
| `Counter(v0, v1, x, y, size, at, land, suffix, sub)` | 滚动数字 | `land` 必须是整数拍，落定时自动“叮”+放射线+星光。 |
| `Shot(punch=0.006)` | 强拍推镜幅度 | 默认 0.006；钩子 0.02–0.025，drop 0.035。 |
| `Shot(flashes=[拍 或 (拍, 峰值)])` | 闪白 | 撞击帧最亮，0.18 秒退完。 |
| `Shot(shake=[拍 或 (拍, 像素)])` | 镜头抖动 | 只配重击（kick）。 |
| `g.pulse(decay, downbeat)` | 自定义元件里取节拍脉冲 | 用于让任意元件随拍呼吸。 |

纯绘制函数在 `adler/fx.py`（`glow`、`rays`、`sparks`、`shine`、`flash_alpha`、`word_pop`、`draw_word`），自定义元件（`Custom(fn)`）里可以直接调用。
新增音色：`engine/perc.py` 的 `pop`（气泡弹出）与 `ding`（亮音叮）。

## 4. 硬约束

- **音效只放整数拍**（实测拍点），小数拍带音效会抛 `ValueError`；无音效的画面动作可以用小数拍。
- **阅读窗**：2 小节镜头字幕 ≤15 汉字（`text_beat=0` 时约 16 字），含数字/英文另加 1 秒；字幕最多 2 行；研究卡至少 4.5 秒。`--sheet` 的警告必须清零。
- 光效不进页眉（y<330）与字幕区（y>1270）——放射线已自动裁剪；自定义压暗/遮罩也要限制在舞台区。
- 诚实：不编数字、不把示意当数据；每期 `notes` 写清出处、示意说明与反面证据。
- 新效果默认关闭，旧系列逐字节不变（改引擎后用旧系列 `--still` 对比 md5 回归）。
