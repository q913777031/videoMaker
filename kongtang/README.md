# 控糖革命 12 讲（无旁白竖屏科普动画）

按杰西·安佐斯佩《控糖革命》（Glucose Revolution）的结构制作：第 01–02 期讲葡萄糖与血糖尖峰，第 03–12 期讲书中的 10 个方法。
与阿德勒、MBTI、星座系列共用引擎（`adler/core.py`、`adler/kit.py`）；本目录放分集脚本、专用元件 `kit_tang.py`（血糖曲线图、食物图标）、
系列常量 `common.py` 与构建入口。卡点规则见 `adler/README.md`。

```bash
python3 -m kongtang.build 03 --sheet     # 逐镜联系表
python3 -m kongtang.build                # 渲染全部 12 期到 out/kongtang/epXX/
python3 -m kongtang.build --verify       # 核验
python3 -m kongtang.build --publish      # 复制到 videos/kongtang/
```
