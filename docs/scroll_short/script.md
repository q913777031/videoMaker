### 6—20 秒｜示意循环
- 标签：示意模型 · 帮助理解，非实验结论
- 节点：看到内容 → 产生反应 → 继续滑动 → 新内容出现
- 下一条【好不好看】，/ 滑之前不知道
- 这份不确定，让人期待 / 【“也许下一条更好”】
  - 依据小字：理论框架：奖励预期与不确定性（Schultz 等，1997）
- 新内容几乎 / 【零等待】出现
- 重复多了，滑动 / 容易变成【习惯】
  - 依据小字：依据：习惯研究综述（Wood & Rünger，2016）

### 48—57 秒｜推荐反馈（示意流程）
- 你的每个动作，/ 都是一次【反馈】
- 系统据此调整下一批内容
- 标签：看完 / 点赞 / 很快划走 → 推荐系统（调整下一批的排序）→ 候选内容 → ↓ 更接近你反馈的排到前面
- 依据小字：TikTok 官方说明（2020）：看完较长视频是强信号；YouTube 论文（2016）：按预测观看时长排序。各平台的具体权重未公开。

### 57—65 秒｜停止节点对照（示意界面）
- 区别在于：/ 有没有【停止节点】
- 左：有终点的列表 → — 到底了 — → 停止节点
- 右：持续加载的列表 → （加载转圈）→ 没有自然终点
- 依据小字：参考：Rixen 等（2023）无限滚动现场研究；欧盟委员会（2026）对无限滚动、自动播放等设计的初步认定

### 65—70 秒｜第四个钩子

- 循环中出现：暂停节点

### 70—84 秒｜一个可以试的方法
- 给循环加一个【停止节点】
- 操作前：滑动 → 下一条 → 滑动 → 下一条 → …
- 加一步：开刷前设个计时，并想好：/ **如果** 提醒响了 / **就** 先锁屏，再决定要不要继续
- 操作后：滑动 → 下一条 → ⏸（停一下）→ 自己决定
- 补回消失的停止节点，/ 也给【习惯】留个出口
- 不保证对每个人有效，可以试一试
- 依据小字：“如果—就”计划有助于执行既定目标（元分析，Gollwitzer & Sheeran 2006）；打开应用前加一道确认，约 36% 的打开被放弃（Grüning 等 2023，280 人，6 周）
