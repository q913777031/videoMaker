| 01.1 | 格竹时二十一岁 | 《年谱》弘治五年（1492）条：在京师父亲官署“取竹格之”，沉思不得，遂遇疾 | 已核（二手转引，待对照《王阳明全集》整理本） |
| 01.2 | 与钱姓友人格亭前竹，钱三日病，阳明七日病 | 《传习录·下》：“初年与钱友同论做圣贤要格天下之物……钱子早夜去穷格竹子的道理……至于三日，便致劳神成疾……到七日，亦以劳思致疾” | 原文已核；所属录（通常归黄以方录）与陈荣捷条目号待核 |
| 01.2 | 两种记载有出入：《传习录》说与友人同格“亭前竹子”，《年谱》说独自格“官署中”的竹 | 同上两处 | 文案用“亭前的竹子”从《传习录》，不提“官署” |
| 01.2 | 十六年后龙场悟道 | 《年谱》正德三年（1508）：“忽中夜大悟格物致知之旨……始知圣人之道，吾性自足，向之求理于事物者误也” | 已核（二手转引）；1508−1492=16 |
| 01.2 | “格物”出自《大学》“致知在格物”，“一草一木皆有理”是程朱的解释 | 《大学》；程颐、朱熹 | 常识，深讲节再展开 |
| — | 不用：“搬椅子坐七天”“对竹子看了七天七夜”等网传细节 | 原文是“早夜去穷格”（日夜苦思），无“坐”“看”的描写 | 已排除 |
| 01.3 | 龙场在今贵州修文 | 今贵阳市修文县龙场镇（多篇介绍一致） | 已核 |
| 01.3 | 住山洞、日夜静坐 | 《年谱》：“日夜端居澄默，以求静一” | 已核（二手转引）；居所是天然溶洞、玩易窝还是阳明洞学界有考证分歧，文案只说“山洞” |
| 01.3 | “如果是圣人，落到这一步，会怎么做？” | 《年谱》：“因念：圣人处此，更有何道？” | **待核**：常见引文，本轮检索未见一手文本；核实前不上屏，只作旁白 |
| 01.3 | 半夜想通、跳起、随从皆惊 | 《年谱》：“忽中夜大悟格物致知之旨，寤寐中若有人语之者，不觉呼跃，从者皆惊” | 已核（二手转引） |
| 01.3 | 原文卡①“圣人之道，吾性自足；向之求理于事物者，误也” | 《年谱》正德三年条（非《传习录》正文） | 已核（二手转引），屏上标“《年谱》” |
| 01.3 | 徐爱问“至善只求诸心，恐于天下事理有不能尽”；答“心即理也。天下又有心外之事、心外之理乎？” | 《传习录·上》徐爱录 | 原文已核；条目号待核 |
| 01.3 | 徐爱是最早的弟子 | 多种资料称“首徒”，《传习录》卷上由他记录 | 已核（二手）；“妹夫”一说本轮未查到出处，**不用** |
| 01.4 | 朱熹：用力之久，一旦豁然贯通 | 朱熹《大学章句·格物补传》“至于用力之久，而一旦豁然贯通焉” | 常见原文；屏上只写“豁然贯通”并标《大学章句》 |
| 01.4 | “孝的道理要到父亲身上去找吗” | 《传习录·上》徐爱录：“且如事父，不成去父上求个孝的理” | 已核 |
| 01.4 | 冬温夏清、根与枝叶 | 《传习录·上》徐爱录：“譬之树木，这诚孝的心便是根，许多条件便是枝叶，须先有根，然后有枝叶，不是先寻了枝叶，然后去种根” | 已核（转载本，叶圣陶点校本为底本） |
| 01.4 | 不用：“父母不在了，孝的道理就没了吗”（《答顾东桥书》） | 本轮未检索到原文 | 已排除 |
