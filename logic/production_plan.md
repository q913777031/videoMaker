# 逻辑训练：三人·三城·三种运动（静音竖屏短视频制作方案）

- 成片规格：9:16，1080×1920，30fps，90 秒；**全程静音，导出时不含音频轨**（不是保留默认音乐后再静音）
- 定位：可以先暂停自测、再跟着动画推理的逻辑小挑战。不标“国考真题”“某年省考题”“官方答案”
- 可编辑源文件：`logic/logic_short.py`（字幕、时间线、配色、版面都集中在文件顶部常量里）
- 核验脚本：`logic/verify_logic.py`（不出现在正片中）

## 6. 核验说明

**一一对应前提**：原图没有另写“运动各不相同”。为消除歧义，视频题干补充“每人对应一座城市、一种运动；城市、运动均不重复”，画面中放在蓝底框并标注“前提”，**不声称这句话逐字出现在原图中**。全片统一用“来自城市”，不写“籍贯”。

**推理链（视频正片顺序）**
1. ③ ⇒ 北京—足球；④ ⇒ 上海—篮球
2. 城市、运动各用一次 ⇒ 推出 广州—排球（推论，不是第六条条件）
3. 乙：② 排除上海—篮球；⑤ 排除排球，借助“广州—排球”排除广州 ⇒ 乙＝北京—足球
