# 荣格心理学 10 讲：制作计划（草稿，待确认后开工）

## 0. 结论

- 形式完全沿用《阿德勒心理学 10 讲》：无旁白竖屏 1080×1920、30fps、每期约 92.6 秒（42 小节，到原曲最后一击，后接约 3 秒尾音），
  纸片剪影人物 + 米色纸面背景，`music/bgm.m4a` 实测拍点卡点，第 8 小节（17.14 秒）drop 处落版概念名。
- 流程按 `kepu-video` skill 走：起草计划 → 事实核验 → 写分镜 → 抽帧/联系表检查 → 成片 → 核验报告 → 登记选题 → 交付。
  画面引擎不用 skill 自带的 `kepu/` 黑金风格，而是复用阿德勒系列引擎（`adler/core.py`、`adler/kit.py`），理由见第 5 节。
- 与阿德勒系列的区分：主色从阿德勒的朱红 `#E2603F` 换成靛蓝 `#3F5A9E`，辅以暗金 `#C99A3B`；角标与片尾系列名改为“荣格心理学 · 10讲”。

## 1. 十期选题

每期遵循阿德勒系列的结构：生活场景钩子（情境演绎）→ 直觉解释（机制示意）→ drop 落版概念 → 荣格原意 → 后人阐释 / 研究证据 →
常见误解 → 小练习 → 收束 → 片尾参考资料与下一讲预告。

| 期 | 概念 | 钩子标题（暂定） | 主要内容 | 主要出处（待核验） |
|----|------|------------------|----------|--------------------|
| 01 | 内倾与外倾 | 安静的人，就是内向吗？ | 荣格的定义是“兴趣与心理能量朝向客体还是主体”，不是“社交能力”；人人两者兼有，只是偏向不同 | 《心理类型》1921（CW6） |
| 02 | 四种心理功能 | MBTI 是荣格发明的吗？ | 思维/情感、感觉/直觉；类型是“倾向”不是“盒子”；MBTI 是 Briggs 与 Myers 母女后来据此编制 | CW6；MBTI 重测信度争议（Pittenger 2005） |
| 03 | 人格面具 | 上班的你，和下班的你，哪个是真的？ | Persona 是个人与社会之间的妥协，不是虚伪；问题在于把面具当成全部的自己 | 《分析心理学两论》（CW7） |
| 04 | 阴影 | 为什么特别受不了某一种人？ | 阴影是不被承认的那部分自己；强烈反感有时是投射 | CW9ii《伊雍》；CW11；《回忆·梦·思考》 |
| 05 | 情结 | 一提那件事，为什么就失控？ | 词语联想实验：反应变慢、心跳出汗暴露“带情感色彩的情结”；“不是我们有情结，而是情结拥有我们”（大意） | 《词语联想研究》1904–1910（CW2）；CW8 |
| 06 | 集体无意识与原型 | 为什么全世界都有“英雄冒险”的故事？ | 个人无意识 vs 集体无意识；原型是“形式”而非遗传的具体画面 | CW9i《原型与集体无意识》 |
| 07 | 梦的补偿 | 梦，是在提醒你什么？ | 荣格认为梦对意识的片面态度起补偿作用，与弗洛伊德“伪装的愿望满足”不同；不搞“解梦词典” | CW8《论梦的本质》；CW10 |
| 08 | 共时性 | 刚想到他，他就打来电话？ | 荣格提出“有意义的巧合”；明确交代这不是被科学验证的规律，人对巧合的记忆有选择性 | 《共时性：非因果联系原则》1952（与泡利合著《自然的解释与心灵》） |
| 09 | 人生的下午 | 35 岁之后，为什么突然迷茫？ | “不能按人生上午的计划过人生的下午”（大意）；中年转向内在意义；研究上“中年危机”并非人人都有 | 《人生的阶段》1930（CW8）；Wethington 2000 |
| 10 | 个体化与自性 | “成为你自己”，到底是什么意思？ | 个体化：整合面具、阴影等部分，成为完整的人；不等于自我中心或与世隔绝；系列收束（顺带交代荣格与弗洛伊德、阿德勒的关系） | CW7；CW9i；《回忆·梦·思考》1962 |

备选（如需替换某一期）：阿尼玛与阿尼姆斯——带有明显的时代性别观念，单独做需要大量“时代局限”说明，暂不入选。

### 必须避免的说法

1. “荣格发明了 MBTI / 16 型人格”。
2. 网传“荣格名言”不加核验就上屏，例如“直到你让无意识变成意识……”“一生的特权是成为你自己”（出处存疑）。
3. 把“内向 = 害羞 / 社恐”“外向 = 会社交”说成荣格的定义；把“内向者靠独处充电”说成荣格原话（是后人的通俗说法）。
4. 把集体无意识说成“遗传的记忆画面”或“种族记忆”。
5. 把共时性说成已被证明的规律，或暗示“宇宙在给你信号”。
6. 解梦词典式的“梦见 X 代表 Y”。
7. “荣格是弗洛伊德的学生”——他是独立执业的精神科医生，两人是合作者，1913 年决裂。
8. 心理困扰只给反思练习，长期困扰提示寻求专业帮助（同阿德勒 01 期第 9 镜）。

## 3. 视觉与角标

- 背景、人物、道具沿用 `adler/kit.py` 的纸片剪影元件；主角沿用同一套人物造型（换衣服配色以区分系列）。
- 每期一个贯穿道具：01 两扇窗（向外/向内）、02 四象限罗盘、03 面具、04 影子（人物投在墙上的影子做出不同动作）、
  05 联想词卡 + 秒表、06 冰山 / 海面下的共同海床、07 梦中的门、08 两只时钟 + 金龟子、09 一天的太阳弧线（上午→下午）、10 曼陀罗圆。
- 角标集合：`情境演绎` / `机制示意` / `荣格的视角` / `荣格原著` / `荣格原著 · 大意` / `后人阐释` / `研究证据` / `常见误解` / `小练习`。
- 字幕规则同阿德勒：每行约 12 字以内、最多 2 行，`【】` 高亮；阅读窗 ≥ max(2 秒, 汉字数 / 4.5)，研究卡至少 4.5 秒。

## 4. 配乐与卡点（按 CLAUDE.md）

- 背景音乐一律 `music/bgm.m4a`；本系列为无旁白精细卡点，用 `bgm.detect()` 实测拍点（同 `adler/core.py` 的 `BEATS`）。
- 镜头以小节计，每期 42 小节，镜头边界覆盖段落边界小节 8 / 20 / 24 / 34 / 38 / 40；带音效的动作取整数拍。
- 打击乐用 `engine/perc.py` 合成，峰值与画面撞击帧同帧或相邻帧，`cue_sheet.csv` 记录每个音效的拍序号与偏差帧数。

## 5. 工程方案

阿德勒系列代码只在分支 `claude/busy-dijkstra-d8zuzs` 上，尚未合入本分支。

| 方案 | 做法 | 代价 / 风险 |
|------|------|-------------|
| A（推荐） | 从该分支取 `adler/` 与 `engine/perc.py` 的改动；新建 `jung/`，复制 `core.py`、`kit.py`、`build.py`，只改系列名、主色、缓存与输出路径 | 两份引擎有重复代码；但不动阿德勒的未合入代码，不会和那条分支冲突 |
| B | 把 `adler/core.py` 抽成通用系列引擎（系列名、配色参数化），阿德勒与荣格共用 | 改动未合入分支上的代码，合并时冲突概率高；需要回归渲染阿德勒 10 期验证没坏 |

目录：`jung/ep01_types.py` … `jung/ep10_individuation.py`、`jung/事实核查.md`、`jung/README.md`；
成片发布到 `videos/jung/XX_概念/`（MP4、cover.png、cue_sheet.csv、文案与出处.md），WAV 不入库。

## 6. 执行步骤

1. 环境：`pip install -r requirements.txt`、`python3 fetch_assets.py`（字体）；确认 `music/bgm.m4a` 存在。
2. 事实核验：逐条联网核验第 2 节，写 `jung/事实核查.md`；核验不了的降级为“大意”或删除。
3. 搭工程（方案 A）：取阿德勒引擎，建 `jung/`，跑通一个空白期确认拍点与片尾。
4. 先做 01 期样片：分镜 → `--sheet` 联系表检查 → 成片 → `--verify` → 发给你看风格，确认后再量产。
5. 02–10 期：每 3 期一批写分镜、联系表检查、修正、成片。
6. 全部 `--verify`：时长、编码、响度（约 -16 LUFS-I、真峰值 ≤ -1 dBTP）、音画偏差帧数、阅读窗。
7. 登记 `plans/topics_registry.md`（该文件在 `claude/magical-ride-fk0au6` 分支，需一并取过来），提交推送，发送成片。
