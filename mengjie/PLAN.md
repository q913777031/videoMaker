## 一、书中事实（写进旁白的，逐条对照原书）

| 旁白说法 | 书中位置 | 说明 |
|---|---|---|
| 一百多年前，一个医生写了《梦的解析》 | 1899 年出版；弗洛伊德是维也纳的神经科医生 | 片中不写具体年份 |
| 晚饭吃得太咸，夜里梦见大口喝水 | 第三章“梦是愿望的满足” | 他自己的例子：晚上吃了鳀鱼、橄榄等很咸的东西，夜里口渴，醒前总梦见在喝水 |
| 小女儿饿了一天，梦里喊着要吃草莓 | 第三章 | 小女儿安娜十九个月大时吐了一次、饿了一天，夜里梦话喊“草莓、野草莓、蛋卷、布丁” |
| 梦是愿望的满足 | 第三章标题与全书主张 | 书中观点，转述 |
| 梦有两层：记得的故事（显梦）和底下的意思（隐梦） | 第六章“梦的工作” | 片中不用“显梦 / 隐梦”术语，只说“两层” |
| 意思要化了妆才出来：几个人捏成一个人（凝缩）、要紧的事换成不起眼的小事（移置） | 第六章 | 书里说梦有“审查”，所以要伪装；片中用“化妆”比方 |
| 考试梦：梦里考的常是早就考过、而且考过了的那一场，像在安慰你 | 第五章“典型的梦”·考试梦 | 弗洛伊德转述一位同事的观察，说这类梦像在说“别怕明天，那次你也怕，结果没事” |
| 读梦的办法：把梦拆开，一块一块问自己想到什么（自由联想） | 第二章 | 书中观点，转述 |
| 别照着词典解梦，同样的东西每个人梦见意思不一样 | 第二章批评“译码法”（按固定词典一对一解梦） | 书里也列过一些常见象征，片中不展开 |

科学性：现在的睡眠与梦研究不支持“每个梦都是愿望的满足”；比较多研究看到梦的内容和白天的事、心里挂着的事有连续性（“连续性假说”）。
片中用两句交代（屏 12），三步做法据此只讲“记下来、找白天的影子、问感受”，不教按符号解梦。

- 04：植物学专著的梦，前一天在书店橱窗看到仙客来的专著；梦挑“无关紧要的”近期印象；童年材料在梦里重现（第五章）。“梦滞后效应”（前一两天和一周左右的经历更常入梦）是今天的研究（Nielsen 等）。
- 05：梦的内容简短、梦念长得多；植物学专著连着同事、妻子爱的花、童年和妹妹撕彩色图册；集体人物与拼合人物（第六章 A）。睡眠整理相近记忆是今天的研究。
